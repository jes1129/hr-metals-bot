📖 使用說明

一頁看懂整個網站怎麼用 · 可展開／可試玩 · 更新於 2026-09-01

這是什麼？

這是一套幫九上科技的免費小型 ERP：一邊自動盯原料行情、找供應商、開發客戶；一邊管報價、訂單，還有 AI 助手（含中越對話）。資料每天自動更新，不用開電腦、不用付費、不用維護。

上面一排分成幾類：🏠 首頁總覽、📈 情報（原料/供應商/客戶，點開是下拉選單）、以及營運工具 🧮 報價 · 📦 訂單 · 🤖 助手 · 🗂️ 資料庫，最後是 📖 說明（本頁）。

點下面任一顆，直接跳到該功能的詳細說明：

新手上路登入🏠 首頁🔩 原料 🏭 供應商🎯 客戶🧮 報價📦 訂單 🤖 助手中越對話🧠 NotebookLM早報信 🗂️ 資料庫/試算表更新頻率/費用常見問題

新手上路：建議使用順序

第一次用不知道從哪開始？照這個順序做一遍，就通了：

  • 用 Google 登入（右上角）——這樣資料才會存進公司試算表、換裝置也看得到。
  • 看情報：📈 情報裡的原料行情、供應商、客戶，平常參考用。
  • 報價：客人詢價 → 🧮 報價算一算 → 存起來。
  • 轉訂單：接到單 → 📦 訂單「從報價轉單」或「＋新增訂單」，用看板追進度。
  • 問 AI：🤖 助手點按鈕或打字，隨時問「哪些逾期 / 本月概況 / 待出貨」；要跟越南員工溝通就切「中越對話」。
只想輕鬆用？每天開首頁看重點卡片、需要時點 🤖 助手問一句，就很夠了。

登入 — 第一件事，資料才會存起來▾

這是什麼：用公司的 Google 帳號登入。登入後你做的收藏、報價、訂單才會存進公司試算表，換手機、換電腦都看得到同一份、不會不見。

怎麼用：

  • 看畫面右上角那顆「使用 Google 帳戶登入」，點它。
  • 跳出視窗，選公司的 Google 帳號登入。
  • 右上角出現你的名字，就成功了。

小撇步：登入後切換分頁不會登出；大約一小時要再登一次是 Google 的安全設計，正常。真的登出了再點一次那顆按鈕就好，資料都還在。

🏠 首頁 — 每天先看這頁▾

這是什麼：每天打開的第一頁，一眼看今天重點。

怎麼看：

  • 最上面是問候＋今日數字：待出貨幾筆、逾期未出幾筆（會標紅）、本月訂單幾筆（登入後才有數字）。
  • 下面兩張大卡＝最常用的 🤖 AI 助手 和 每日早報，點就進去。
  • 再下面「快速前往」小圖示＝其他功能（原料、報價、供應商、客戶、資料庫、說明⋯），點一下就到。

小撇步：只想輕鬆用？每天看一眼首頁「逾期未出」有沒有紅字，就大概知道今天要不要盯。

🔩 原料 — 銅／鋁 價格▾

這是什麼：盯銅、鋁的國際價格（已換算成台幣），幫你判斷進料成本。

怎麼看：每種金屬一張卡，有現價、今天漲跌、走勢圖。上方可切單位（每公噸／每磅）與期間（近 7／30／90 天、一年）看漲跌幅；最下面附相關新聞，了解漲跌原因。

小撇步：紅色↑＝變貴、進料成本要留意；綠色↓或平平＝安心。系統只給你價格，不設警報，由你自己判斷。

📦 訂單 · 進度儀表板 — 建單、狀態看板▾

這是什麼：把接到的單記進來，用看板追每張單的進度。畫面不顯示金額（避免員工看到營收）。

小撇步：單價／金額還是可以填、會存起來記帳，只是不顯示在看板。要看金額到「🗂️ 資料庫 → 訂單」分頁。

🤖 AI 助手 — 用問的查資料▾

這是什麼：用問的就能查公司資料、也能教你怎麼用網站。

怎麼用：登入後，點上面的快速鈕（教我用網站、哪些訂單逾期、本月概況、待出貨），或直接打字問。

小撇步：想讓它像 ChatGPT 什麼都能聊，要一次性啟用免費 AI（下面步驟，工程師幫忙一次就好）；不設定也能用上面的快速問答。

（選用）啟用「自由提問」：一次性設定（用免費 Groq）

  1. 去 console.groq.com 用 Google 登入，建立免費 API 金鑰（免綁卡，複製起來）。
  2. 打開公司試算表 → 擴充功能 → Apps Script → 左側 「專案設定」⚙️。
  3. 下方 「指令碼屬性」→ 新增屬性：名稱填 GROQ_API_KEY、值貼上金鑰 → 儲存。
  4. 回程式碼把最新版 google-apps-script.gs 貼上、重新部署（新版本）即可。

中越對話 — 跟越南員工溝通▾

這是什麼：讓老闆和越南員工雙向溝通。在「🤖 助手」頁的最上方，切到「中越對話」就是。

怎麼用（超簡單）：

  • 常用句：點「停機／換刀／小心／休息⋯」任一顆，畫面立刻同時顯示中文＋越南文，把手機拿給對方看就懂。免登入、免設定、即時。
  • 🎤 語音：手機沒有越南文鍵盤？按「🎤 Nói tiếng Việt」直接用嘴巴講越南文，它自動辨識再翻成中文（講中文也可以）。
  • 打字翻譯：打一句話按「翻譯」，自動判斷中↔越。

小撇步：常用句永遠免費、沒網路也能用；語音／打字翻譯需登入＋啟用免費 AI，語音建議用 Android 版 Chrome（iPhone Safari 多半不支援，會提示改打字）。

🧠 NotebookLM 知識庫 — 進階／選用▾

這是什麼（白話）：NotebookLM 是 Google 免費的「AI 問答筆記本」。我們每天自動幫你寫好一份「公司近況文件」，你把它放進 NotebookLM，它就變成一個只懂你公司的 AI——可以用問的，還能生成語音摘要用聽的。

怎麼用：

  • 點下面「開啟 NotebookLM →」（會開新分頁）。
  • 第一次：在裡面按「+ 新增來源／Add source」，把我們那份 Google 文件加進去（工程師幫你設好，加一次就好）。
  • 之後想問就打字問它：「這個月往來重點？」「跟大雅精密進度到哪？」，它會附出處回答。
  • 想用聽的：按「Audio Overview／生成語音摘要」，把近況變成兩人對談，巡廠、開車用聽的。
文件不會自己跑進去——第一次要手動加來源一次；之後我們改寫同一份文件，你在該來源按「同步」就更新，不用重加。
免費。但「語音摘要」每天能生成的次數有限，需要時再生成、不必每天；純打字問答日常用不會超過。

每日早報信 — 每天早上自動寄給你▾

這是什麼：不用開網站，平日早上系統自動把「今天要注意的事」寄到你的信箱（週末工廠休就不寄）。

小撇步：這封信只寄到你設定的信箱，員工看不到。收不到請工程師確認收件人設定（一次性）。

免費。一天一封，離 Gmail 每天 100 封的上限差得很遠。

會不會被收費？不會。

整套跑在免費額度上（GitHub＋Google＋免費 AI），關機也會自己在雲端更新，不會跟你收錢。唯一要知道的是免費額度的「每日上限」——超過只是當天暫時擋一下，不是收費：

  • 🧠 NotebookLM：每天自動更新的只是「寫一份文件」（免費、無限）。你手動生成的「語音摘要」每天次數有限——需要時再生成、別每天狂產。
  • 🤖 AI 問答／翻譯：免費有每分鐘上限；日常問幾句遠低於，短時間狂刷才會暫時擋，等幾分鐘就好。
  • 每日早報：一天一封，離 Gmail 每天 100 封上限差很遠。
一句話：正常使用完全免費、不會超量；唯一要節制的是 NotebookLM 的「語音摘要」別每天狂生成。

🗂️ 平常這樣用：站內「資料庫」就好，不用開試算表

上面導覽列的「🗂️ 資料庫」是站內操作中心——不必打開 Google 試算表，直接在網站上就能管理所有資料（下面詳述）。

想看原始的 Google 試算表？（通常用不到）

  • 到首頁點「🗂️ 九上資料庫」卡片，或站內「🗂️ 資料庫」底部的「開啟原始試算表」。

  • 看看就好、通常不用手動改；要改資料用站內「🗂️ 資料庫」比較安全好操作。

登入後能做什麼（下面可以試玩）

⭐ 收藏：點星星試試 → ☆ 未收藏
狀態：點按鈕切換 → 未設定

🗂️ 資料庫操作中心（免開試算表）

上方分頁的「🗂️ 資料庫」是站內操作中心——不必打開 Google 試算表，直接在網站上就能管理資料：

  • 四個資料表：我的名單/待辦、收藏與標記、報價歷史、訂單，點分頁切換。
  • 新增／編輯／刪除：點「＋ 新增」或每列的 ✏️／🗑️，跳出小表單填一填就好。
  • 搜尋／篩選／排序：上方搜尋框打字即時過濾、點欄位標題排序、用下拉篩狀態。
  • ⬇ 匯出 CSV：一鍵下載成 Excel 可開的檔案。
  • 可視化：上方有筆數與各狀態統計、分佈長條圖。
  • 新手：第一次用可按「載入範例資料」看看長怎樣，之後再清掉。
手機上表格會自動變成一張張卡片，好點好讀。需要看原始試算表時，操作中心底部也有「開啟原始試算表」連結。

常見問題

登出了怎麼辦？▾

再點一次右上角「使用 Google 帳戶登入」就好。收藏／備註都還在（存在試算表裡，不會不見）。

看不到最新資料？▾

按 Ctrl + F5（Mac 是 Cmd + Shift + R）強制重新整理一次即可。原料價一天更新兩次；供應商／客戶名單每月更新一次；訂單／報價／名單是你一存就即時同步。詳見上面「各功能多久更新一次」。

名單好像只顯示一部分？▾

頁面上為了速度只放最相關的前 600 筆（已按「離神岡近／有分類」排序）。完整名單在 Google 試算表裡，點首頁「🗂️ 九上資料庫」就能看全部。

要錢嗎？▾

不用。整套跑在免費服務上（GitHub＋Google＋免費 AI），關機也會自己在雲端更新，不會跟你收錢。唯一要節制的是 NotebookLM 的「語音摘要」別每天狂生成（有每日免費上限）。詳見上面「各功能多久更新一次？會不會花錢？」。
